# Implementation Plans — Post-Mortem Remediation (2026-07-05)

Companion to `docs/POSTMORTEM_2026-07-05.md`. Plans are grouped into clusters, ordered by priority (what must be fixed before what else works), and each is tagged **OPUS_SAFE** (well-defined, self-contained, subagent-verifiable) or **FABLE_SUPERVISED** (cross-system judgment, calibration, or security-critical decisions).

Delegation rule applied: security decisions that require knowing whether a client caller sends a token = FABLE. Purely mechanical, template-following, single-file changes with a local verification = OPUS. When unsure → FABLE.

### P1-D. OAuth `state` CSRF binding — **FABLE_SUPERVISED** (plan only this session)
